What the contract will and will not do

The desk is a window. These rules are the ones in contracts/lockstep.py.

Frozen manifest

There is no edit, reorder, or skip call. The spec stored at funding is the spec that settles.

Contract-built URLs

npm, PyPI, and GitHub Releases only. A sponsor cannot point a fact gate at a page they control.

Order

The next open gate is the only one that can close. A signature waits behind a registry read.

Fail closed

An unreadable source, a draft GitHub release, or a yanked PyPI file leaves the gate open. It is not a match and it is not a refund, until the deadline.

Terminal transfer

Settle pays the payee the full deposit once every gate is closed, including after the deadline. Refund pays the sponsor only when the deadline has passed and a gate is still open.

Unwind

Sponsor and payee can both consent. Either one is not enough, unless they are the same account. Then anyone can unwind the deposit back to the sponsor.
